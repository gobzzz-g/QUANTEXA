## 💡 Top 5 Judge Questions & Quick Answers

If presenting to hackathon judges or clients:

- **Q1: How do you handle calendar differences (Crypto 365 days vs Equities 252 days)?**  
  *A:* "We evaluate each asset on its native trading calendar. For cross-asset correlation or joint backtesting, we perform strict inner joins on overlapping trading dates without forward-filling weekend prices into equity data."

- **Q2: How do you prevent Look-Ahead Bias in backtests?**  
  *A:* "Signals are calculated strictly using data up to day $t$'s close. The simulated execution order is executed on day $t+1$'s Open price."

- **Q3: What happens if an external data API (like yfinance) goes down?**  
  *A:* "QuantExa features automated fallback to local verified seed datasets (`data/seed`), ensuring 100% uptime and seamless demo reliability."

- **Q4: What is QUBO and why use it for portfolio optimization?**  
  *A:* "QUBO formulates discrete asset selection as a binary quadratic problem. We solve it using simulated annealing, allowing discrete index tracking and cardinally constrained allocation."

- **Q5: Is the system fully containerized and production-ready?**  
  *A:* "Yes. The backend uses modular FastAPI endpoints, pandas vectorization, Supabase PostgreSQL persistence, and Docker support for deployment."
